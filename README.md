# Perlica Charms ✨

Progetto e-commerce frontend mobile-first sviluppato per un brand artigianale di gioielli (collane di perline, braccialetti e cavigliere).

## Tecnologie Utilizzate
• **React.js** (con Vite) per la struttura modulare dei componenti.
• **React Router** per la navigazione fluida tra le pagine.
• **Tailwind CSS** per il design system personalizzato (ispirato a un'estetica mediterranea e warm-minimalist).

## Pagine Principali
• **Homepage:** Vetrina interattiva con sezioni editoriali, categorie in evidenza e nuovi arrivi.
• **Catalogo:** Griglia prodotti con layout responsive e filtri interattivi.
• **Chi Siamo (Storytelling):** Sezione dedicata al racconto del brand e al processo artigianale.
• **Carrello:** Schermata di riepilogo articoli con calcolo dei totali.
